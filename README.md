# Passive Integrated ESD Mitigation System for Lunar EVA
**Submitted to:** NASA Lunar Grounding Challenge
**Author:** SIFI BOUKHARI (Senior Construction Technician, 30+ Years Experience)
**Location:** Algeria

## 📌 Project Overview
This repository contains the complete technical proposal, simulation codes, and risk assessments for a zero-power, lightweight (<1.5 kg) Passive Electrostatic Discharge (ESD) Mitigation System designed for the Lunar South Pole. 

The system utilizes an external "Over-Suit" (to avoid modifying the primary $12M spacesuit) coated with MXene to collect triboelectric charges. The charge is safely transferred through silver straps to a high-resistance (500 MΩ) bronze contact point in the boot heel, and dissipated through a Biochar-based landing mat.

## 📂 Repository Contents
*   **PDF Documents:** Full submission files (Concept Description, Electrical Analysis, Risk Assessment).
*   **Python Scripts (.py):** Simulation codes verifying safety limits.
*   **Images:** Execution screenshots of the thermal, cryogenic, and dust simulations.

## 🚀 Key Results & Compliance
*   **Safety:** Max current limited to 0.2 mA (NASA limit: < 1.0 mA).
*   **Speed:** Full discharge in 2.5 seconds (Target: < 30 seconds).
*   **Weight:** < 1.5 kg for the full Over-Suit system (Limit: < 20 kg).
*   **Power:** 0 Watts required (Passive system).
*   **Dual-Use:** Biochar composite offers terrestrial spinoffs for hospital flooring, cleanrooms, and EV tires.
